## 📊 Dataset
`data/customer_data.csv` contains ~4,000 subscription customer records:

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| SignupDate | Date the customer signed up |
| Plan | Basic / Standard / Premium |
| MonthlyPrice | Monthly subscription price |
| ContractType | Monthly or Annual |
| Region | Customer region |
| AcquisitionChannel | How the customer was acquired |
| SupportTier | Self-Service / Standard Support / Priority Support |
| TenureMonths | Months as an active or former customer |
| AvgLoginsPerMonth | Average product logins per month (engagement) |
| SupportTickets | Number of support tickets raised |
| SatisfactionScore | Self-reported satisfaction (1–10) |
| Churned | 1 = churned, 0 = retained |
| ChurnDate | Date of churn (blank if still active) |
| CustomerLifetimeValue | Total revenue generated by the customer |

> **Note:** This is a synthetically generated but realistic dataset (~27% churn rate, consistent with typical subscription businesses) with intentional data-quality issues cleaned within the notebook. Swap in your own dataset with matching column names and the notebook runs unchanged.

## 🔍 Key Insights
1. Monthly-contract customers churn far more than annual-contract customers.
2. Low product engagement (login frequency) is the strongest early churn signal.
3. Self-Service support tier has the highest churn rate.
4. Satisfaction score reliably predicts churn.
5. Premium plan customers carry the highest CLV but aren't immune to churn.
6. Churn rate varies meaningfully by acquisition channel.

## ✅ Recommendations
- Incentivize switching from monthly to annual contracts.
- Build an engagement early-warning system to trigger re-engagement campaigns.
- Move at-risk Self-Service customers to proactive support.
- Run satisfaction pulse surveys and act on low scores early.
- Reallocate acquisition budget away from high-churn channels.
- Launch a win-back campaign for recently churned customers.
